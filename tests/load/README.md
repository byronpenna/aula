Pendiente de ejecutar contra un ambiente desplegado (staging), no contra local
(sección 12). `assignment-save.js` es un script k6 de referencia para el escenario
"pico de validación" (guardado de respuestas concurrente); requiere `k6` instalado y
una URL de API real, y datos sintéticos, nunca datos reales de alumnos.
